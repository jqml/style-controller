# Style Controller 0.1.40

This release adds the validated settings and image improvements developed since 0.1.39. The compact two-level navigation, lazy rendering, existing profiles, saved configurations, Reading View matching, and PDF export remain available.

- **Context-aware sticky Apply/Revert:** compact action rows stay at the top of the content scroller while their owning group is visible. Each section, override, callout style/spacing group, and advanced layout retains its independent draft and save boundary. Saved-state feedback stays in the action row without success popups covering controls.
- **Original Named Callouts layout:** retain the published responsive two-column card grid, card dimensions, spacing, and ordering. Each card has independent, ordinary non-sticky Revert/Apply actions; narrow windows wrap as before.
- **Stable Live Preview table images:** preserve the native shrink-to-fit image wrapper inside editable table cells, preventing a configured wrapper width from becoming a new column minimum on selection. Image width styling, explicit dimensions, aspect ratios, resize handles, lightbox, Reading View, and PDF styling remain intact.
- **Note and folder Image Rules:** configure image width, alignment, and respect for explicit dimensions under Global Defaults → Images. Rules reuse the existing path-override engine, independently Apply/Revert, inherit unspecified fields, and retain existing override precedence and configuration export/import behavior.
- **Shared fuzzy path autocomplete:** Overrides, File Explorer Overrides, and Image Rules use one compact owner-window dropdown with match highlighting, full-path tooltips, keyboard and mouse selection, bounded scrolling, and automatic placement near window edges. Image Rules filter suggestions by Markdown note or folder and include Use current note. No dependency on another plugin.

Includes source-level regression tests and Pro-only native checks for sticky group boundaries, published Named Callout geometry, independent saving, table image selection, shared autocomplete, draft preservation, and persistence at 620/720/1000px widths. Existing saved settings and note contents require no migration.
